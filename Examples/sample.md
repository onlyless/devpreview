# DevPreview

在 Finder 里按空格，直接看代码。

## 支持

- 语法高亮：`Swift`、`Go`、`Rust`、`Python`、`TypeScript`
- 行号与等宽字体
- UTF-8 / UTF-16 / GB18030 编码识别
- 大文件自动截断与降级

```swift
struct Greeting {
    let name: String

    func render() -> String {
        "Hello, \(name)!"
    }
}
```

> 所有内容都在本机解析，不会上传。

更多信息见 [项目说明](README.md)。
